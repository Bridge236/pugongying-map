# 蒲公英 · 同学地图

> 一款轻量级的同学位置可视化工具，基于 Leaflet.js 构建，数据存储在浏览器本地。

## 功能特性

- 🗺️ 中国地图可视化，标记同学所在省份
- 👤 头像气泡标记，自动分配专属颜色
- 📍 同省多人头像自动散开，不遮挡
- 💾 数据本地存储（localStorage），无需后端
- 📱 响应式设计

## 使用方法

直接访问网站，点击「添加同学」填写姓名、学校、省份即可。

## 技术栈

- 纯 HTML / CSS / JavaScript（单文件）
- [Leaflet.js](https://leafletjs.com/) v1.9.4
- [OpenStreetMap](https://www.openstreetmap.org/) 地图图层
